# Publisher releases

Publisher is a Windows release tracker. This repository hosts its public installers and signed update feed.

## Download

Get the latest installer from the [Releases page](https://github.com/5Y3D-Bilal/publisher-releases/releases/latest). Each release includes:

- `Publisher_Setup_<version>_win64.exe`: the Windows installer
- `Publisher_<version>_win64.zip`: the portable Windows package
- `latest` and `latest.sig`: the update feed and its signature

## Supported platforms

- Windows 64-bit

## Verify and update

Each release ships `latest.sig`, the signature for the `latest` update feed. Install a newer release from the Releases page when one is published.

## Source code

This repository contains no source code, only download files and the update feed.
